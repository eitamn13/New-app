# 🧾 קַבָּלָה — סורק קבלות חכם

אפליקציית web ניידת (PWA) שסורקת ברקוד של מוצר, **מזהה אותו ממאגר מוצרים אמיתי**,
מצלמת אותו, ובונה ממנו **קבלה מעוצבת** — עם **היסטוריה וקטלוג משותף בענן (Supabase)**.

עיצוב כהה-אלגנטי, מבטא אזמרגד, נייר קבלה אמיתי עם פרפורציה ובַּרקוד.

---

## ✨ מה האפליקציה עושה

### 1. סריקה חכמה
- מצלמה חיה עם reticle ולייזר סריקה אנימטיבי (ZXing — EAN-13/8, UPC, Code-128 ועוד).
- בכל סריקה: ביפ + רטט + צילום פריים של המוצר.

### 2. זיהוי מוצר אמיתי — 3 שכבות
1. **קטלוג ענן משותף** — אם מישהו כבר סרק את המוצר, השם, המחיר והתמונה נטענים מיד (☁).
2. **Open Food Facts** — מאגר מוצרים עולמי, פתוח וחינמי. שולף **שם, מותג ותמונה אמיתיים** לפי הברקוד (✓).
3. **חדש** — אם המוצר לא מוכר, מזינים שם + מחיר; הוא נשמר אוטומטית לקטלוג המשותף לכל המשתמשים.

### 3. עגלה וקבלה
- עגלה צפה עם סכום חי.
- קבלה בעיצוב נייר אמיתי: פרפורציה, תמונות מוצרים, מע״מ 18% כלול, סה״כ, מס׳ קבלה ובַּרקוד.
- **שמירה לענן** · **שיתוף** (Web Share / הדפסה ל-PDF).

### 4. היסטוריה (בענן)
- כל הקבלות שלך נשמרות ב-Supabase ומסונכרנות למכשיר.
- סטטיסטיקות: מספר קבלות, סך הוצאות, סך פריטים. לחיצה על קבלה פותחת אותה מחדש.

### 5. קטלוג משותף
- חיפוש חי לפי שם / מותג / ברקוד על פני הקטלוג המשותף.
- לחיצה על מוצר → קפיצה לסריקה עם הפרטים מוכנים.

---

## 🏗️ ארכיטקטורה

```
דפדפן (PWA)
 ├─ ZXing            → סריקת ברקוד מהמצלמה
 ├─ Open Food Facts  → מאגר מוצרים אמיתי (שם/מותג/תמונה)
 └─ Supabase (REST)  → קטלוג משותף + היסטוריית קבלות
       ├─ rcpt_catalog        (קטלוג מוצרים משותף)
       ├─ rcpt_receipts       (קבלות לפי device_id)
       ├─ rcpt_receipt_items  (פריטי קבלה)
       └─ rcpt_upsert_catalog (פונקציית RPC, מונה סריקות)
```

- **ללא הרשמה** — לכל מכשיר `device_id` מקומי שמסנן את ההיסטוריה שלו; הקטלוג משותף לכולם.
- **RLS מופעל** על כל הטבלאות עם policies לגישה אנונימית מבוקרת.

### קבצים
| קובץ | תיאור |
|------|-------|
| `index.html` | מבנה (3 טאבים: סריקה / היסטוריה / קטלוג + sheets) |
| `styles.css` | מערכת עיצוב מלאה |
| `app.js` | לוגיקה: סריקה, זיהוי, עגלה, קבלה, ענן |
| `config.js` | כתובת + מפתח Supabase (publishable, בטוח לצד-לקוח) |
| `manifest.json`, `sw.js` | PWA + offline |

## 🚀 הרצה

המצלמה דורשת **HTTPS** או **localhost**:

```bash
python3 -m http.server 8000   # → http://localhost:8000
# או:  npx serve .
```

לנייד: לארח ב-GitHub Pages / Netlify / Vercel (HTTPS) ולפתוח בטלפון → "הוסף למסך הבית".

---

## 🔐 הערות

- `config.js` מכיל מפתח **publishable** של Supabase — מיועד לצד-לקוח ומוגן ע״י RLS.
- כל הנתונים האישיים מסוננים לפי `device_id`; הקטלוג מכוון להיות משותף ושיתופי.
- מחירים מוזנים ע״י המשתמשים (אין מאגר מחירים ארצי חינמי) — הקטלוג "לומד" אותם ומשתף.
