# 🧾 סורק קבלות (Barcode Receipt App)

אפליקציית web ניידת (PWA) שסורקת את הברקוד של כל מוצר בחנות, מצלמת אותו,
ומפיקה ממנו **קבלה** בעברית בסגנון קבלת חנות אמיתית.

## איך זה עובד

1. **מפעילים את המצלמה** ומכוונים אותה לברקוד של המוצר.
2. האפליקציה **מזהה את הברקוד**, **מצלמת תמונת פריים של המוצר** ומשמיעה ביפ.
3. נפתח חלון להזנת **שם מוצר + מחיר + כמות** (אם המוצר כבר נסרק בעבר — הפרטים מתמלאים אוטומטית).
4. הפריט נכנס ל**עגלה**, וכשמסיימים — לוחצים **"צפה בקבלה"**.
5. נוצרת **קבלה** עם רשימת הפריטים, תמונות, מע"מ 18% כלול, סה"כ לתשלום וברקוד.
6. אפשר **להדפיס / לשמור כ-PDF** (כפתור הדפסה).

## תכונות

- 📷 סריקת ברקוד דרך מצלמת המכשיר (ZXing) — תומך EAN-13, EAN-8, UPC, Code-128 ועוד.
- 🖼️ צילום אוטומטי של תמונת המוצר בעת הסריקה.
- 🧠 **קטלוג נלמד** — ברקוד שכבר הוזן נשמר מקומית, וסריקה חוזרת ממלאת שם + מחיר אוטומטית.
- ⌨️ הזנה ידנית כשאין מצלמה / ברקוד.
- 🧾 קבלה בעברית RTL, מע"מ כלול, מספר קבלה ותאריך.
- 🖨️ הדפסה / שמירה כ-PDF.
- 📲 PWA — ניתן "להוסיף למסך הבית" ולהשתמש כאפליקציה.
- 💾 הכול נשמר בדפדפן (localStorage) — ללא שרת, ללא הרשמה.

## הרצה

זו אפליקציית front-end סטטית. כדי שהמצלמה תעבוד צריך **HTTPS** או **localhost**.

```bash
# אופציה 1 — שרת מקומי פשוט
python3 -m http.server 8000
# ואז לפתוח: http://localhost:8000

# אופציה 2 — npx
npx serve .
```

לשימוש מהנייד: יש לארח את התיקייה בכל שירות סטטי עם HTTPS
(GitHub Pages / Netlify / Vercel) ולפתוח את הקישור בטלפון.

## קבצים

| קובץ | תיאור |
|------|-------|
| `index.html` | מבנה האפליקציה |
| `styles.css` | עיצוב (כולל סגנון הקבלה + הדפסה) |
| `app.js` | לוגיקה: סריקה, צילום, עגלה, קבלה |
| `manifest.json` | הגדרות PWA |
| `sw.js` | Service Worker לעבודה offline |

## הערות

- זיהוי ברקוד אינו שולף מחיר אמיתי משום מאגר חיצוני — בפעם הראשונה מזינים מחיר ושם,
  ומשם המערכת זוכרת אותם לכל ברקוד.
- כל הנתונים נשארים על המכשיר בלבד.
